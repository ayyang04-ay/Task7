# PSLN-344 portfolio review — deliverables (1 Nov 2026)

| File | What it is |
|---|---|
| `PSLN-344_portfolio_review_proposal.pdf` | Committee document: recommendation, next steps (gated studies with endpoints and go/kill criteria), TAM target demographic, MoA, biomarkers, supporting evidence, integrity findings, options ruled out, and what is given up if dropped. Figures are in Appendix C. |
| `PSLN-344_portfolio_review_proposal.md` | Same content as editable Markdown. |
| `PSLN-344_evidence_tables.xlsx` | Evidence behind every number. ET1 = claims index (each headline number independently recomputed, with source block, cells and method); ET2–ET7 = efficacy, survival, mechanism and restoration analyses; ET8–ET12 = data-integrity register and evidence; ET13–ET15 = every per-animal value with its original cell address. |
| `figures/` | Fig. 1–7 as PNG files (effect sizes, restoration index, survival curves, pooled survival tiers, integrity evidence, MoA schematic, safety readouts). |
| `code/` | Scripts that reproduce everything from `psln_program_dataset.xlsx` (`run_all.sh`). A clean re-run reproduced all intermediate tables byte-for-byte. |

Sources used: `psln_program_dataset.xlsx` and `psln_program_annotation.pdf` only. The few pieces of external context (competitive landscape and licensed-product facts) are labelled as such in the text for market research to verify.
