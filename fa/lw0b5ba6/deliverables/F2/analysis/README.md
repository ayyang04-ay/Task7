# PSLN-344 analysis: how the numbers were produced

Everything in `PSLN-344_portfolio_proposal.docx` and `PSLN-344_evidence_ledger.xlsx` is generated by the scripts in
this folder from `psln_program_dataset.xlsx`. The annotation PDF was read by hand; design facts taken from it are
transcribed in `01_extract_blocks.py` (block geometry) and `04_survival_stats.py` (challenge designs).

Run `./run_all.sh` (about 5 minutes). Paths are absolute (`/tmp/world/filesystem`, `/tmp/outputs`); edit the
constants at the top of each script if the files move. Scripts 04, 05, 08 and 09 need `lifelines` (conda env
`core`); the others need `openpyxl` (env `chem`); `pandoc` comes from env `genomics`.

| Script | What it does | Main outputs |
|---|---|---|
| 01_extract_blocks.py | Assigns every numeric cell of the workbook to a block, keeping its cell address | tidy/continuous.csv, survival.csv, bodyweight.csv |
| 02_integrity_checks.py | Printed n vs rows; repeated series; derived blocks recomputed; frozen body weights; identical survival arms | integrity/*.csv, integrity_report.txt |
| 02b_bodyweight_duplicates.py | Body-weight series that recur between blocks (real readings only) | integrity/B2_* |
| 03_continuous_stats.py | Group statistics and all pairwise tests for every continuous block | stats/continuous_summary.csv, continuous_pairwise.csv |
| 04_survival_stats.py | Survivors, exact CIs, log-rank (exact permutation), Fisher, per block | stats/survival_by_arm.csv, survival_pairwise.csv |
| 05_survival_pooled.py | Pooled survival in aged animals under three readings; survival vs body-weight reconciliation | stats/survival_pooled*.csv, survival_reconciliation.csv |
| 06_bodyweight_stats.py | Peak weight loss per arm with dead animals handled explicitly | stats/bodyweight_by_arm.csv, bodyweight_daily.csv |
| 07_special_analyses.py | Dose-response fit (S08-A); S09-A log10 panels; S11-A vs S11-B; time courses; prime vs boost; young animals | stats/S08A_*, S09A_*, special_analyses.txt |
| 08_sensitivity_power.py | Subset sensitivity of the pooled result; durability contrasts; weight at death; power table | stats/survival_sensitivity.csv, power_table.csv, sensitivity_power.txt |
| 09 to 13 | Figures 1 to 5 and the Kaplan-Meier appendix figure | ../figures/*.png, stats/restoration_chain.csv |
| 14_build_report.py | Proposal text and evidence ledger, every number looked up from the tables above | report_src/proposal.html, ledger.json |
| 15_make_docx.py | Styled DOCX via pandoc | ../PSLN-344_portfolio_proposal.docx |
| 16_build_xlsx.py | Evidence workbook | ../PSLN-344_evidence_ledger.xlsx |

`integrity_log.py` holds the curated integrity findings (Appendix D); `report_numbers.py` holds the lookup helpers
used by script 14; `figstyle.py` the plotting style.
